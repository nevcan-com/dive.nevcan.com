# nevcan.com versions

Nev's numbering (2026-11-11): **v5 = nevcan.com_v2022** (live on nevcan.com now) and
**v6 = this project** (the 2026 build). The earlier versions come from the Wayback Machine
(web.archive.org): every snapshot of nevcan.com whose content changed (35), grouped by design.
`nevcan-com-wayback.png` shows all 35 in order. Browse any year:
https://web.archive.org/web/*/nevcan.com
